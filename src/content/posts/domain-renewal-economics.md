我翻信用卡账单的时候，发现有六笔每年重复的小额扣款，加起来不到一千块，但我完全想不起来它们是什么。

查了一下，全是域名续费。有些是我三年前注册后就没再碰过的，有些是当时想着"先占着以后用"，还有一些是给已经下线的项目留的。

那一刻我才意识到，域名是一种特别隐蔽的支出：单价不高，自动续费，扣款安静，很容易累积成一堆没人管的数字资产。

这篇写我清理这堆域名的过程，以及在这个过程中弄明白的定价逻辑。

## 一、第一年十块，第二年一百二

几乎所有注册商都在用同一套引流策略：新注册首年极低价，续费按原价。

你在首页看到的是"十元起"，点进去选了一个看起来不错的后缀，结账时确实是十块。但你没有注意到页面底部那行小字：续费价格一百二十元。

这个差价不是欺诈，是行业惯例。首年的低价是注册商自己贴钱做的获客成本，续费才是它真正的收入来源。

问题在于，大部分人注册域名是抱着"试试看"的心态，第一年便宜就买了，一年后自动续费扣款，金额变了也不会特意通知你。

我算过自己那批域名，首年平均二十块，续费平均一百一，差价五倍多。如果一直不清理，十年下来是几万块的沉默支出。

## 二、注册局和注册商是两个角色

要理解价格，得先分清这两个角色。

注册局是管理某个顶级域名的机构。比如某个后缀归某家机构管，它制定这个后缀的批发价，向注册商收钱。

注册商是直接卖给你的公司。它从注册局批发，加价零售。

所以你付的钱里，一部分是注册局的批发价，一部分是注册商的加价。

注册局的批发价通常稳定，但也可能涨。某些小众后缀因为注册量不足，注册局会逐年提价来维持运营，涨幅可能很大。这是续费价格变动的一个主要来源。

注册商的加价则完全市场化，同一后缀在不同注册商那里，续费价能差一倍。

## 三、后缀的价格差异有多大

不同后缀的价格结构差别极大，这是选域名时最该看的一点。

老牌通用后缀注册量大、竞争充分，批发价低，续费相对便宜。一些国家或地区的后缀，因为政策原因价格便宜，但可能有居住要求。

新通用后缀花样最多。有些首年几块钱，续费几十；有些首年就很贵，但价格稳定。还有一类是"溢价域名"，某些短词、好词被单独定价，一年几百上千。

我踩过的坑是选了一个看起来很酷的新后缀，首年十五块，第二年续费两百八。查了注册局的政策才知道，这个后缀的批发价每年在涨。

现在的习惯是：注册前先查这个后缀近三年的续费价走势，而不是只看首年。

## 四、转入转出的规则

注册商不是绑定的，域名可以转移。

转移的基本规则是：域名注册满六十天才能转出；转出前要解锁并拿到授权码；转入方会收一笔转入费，通常等于一年的续费价，同时把你的到期时间延长一年。

所以转移本身不额外花钱，你付的转入费等于提前续了一年。

转移的价值在于换到更便宜的注册商，或者换到服务更好的。我有一批域名从一家贵但界面好看的注册商，转到了便宜但界面难看的，一年省下几百块。

要注意的是，转移期间域名不能改 DNS，网站可能短暂受影响。挑流量低的时候做。

## 五、自动续费是双刃剑

自动续费能防丢域名，也能悄悄扣钱。

我的建议是分两类处理：核心域名开自动续费，并且保证绑定的支付方式长期有效；试验性域名关掉自动续费，到期前自己判断要不要留。

最糟的情况是，你以为开了自动续费很安全，结果绑定的卡过期了，扣款失败，域名在宽限期后掉线。这种事我遇到过一次，一个跑了三年的小站突然打不开，排查半天才发现是域名过期。

所以开了自动续费也要定期检查支付方式是否有效，以及注册商有没有发续费失败的邮件。

## 六、到期之后会发生什么

域名到期不是立刻消失，中间有几个阶段。

到期后有宽限期，通常几十天，这期间域名还能正常续费，网站可能已经不能访问，但所有权还在你手上。

宽限期之后进入赎回期，这时候续费要多付一笔赎回费，金额可能是正常续费的好几倍。这个阶段是给"不小心忘了"的人留的补救窗口。

赎回期之后会被释放，重新回到公开市场，任何人都能注册。

这套机制意味着，忘记续费不会立刻失去域名，但补救成本很高。而且有些注册商在宽限期就开始停解析，网站会先挂掉。

## 七、抢注和赎回的现实

如果域名被释放，会有很多人盯着抢。

抢注已经是一个成熟的产业，有专门的工具在释放的瞬间提交注册请求。个人手动去抢，成功率极低。

所以真正的建议是：重要域名绝不能让它过期。赎回的成本再高，也比抢回来便宜。

我见过一个案例，一个人忘了续费一个用了五年的个人博客域名，被抢注之后，对方开价几千。他咬牙买回来了，因为所有外链、搜索引擎收录、读者书签都指向那个域名，换域名的损失远大于几千块。

## 八、域名数量是怎么膨胀的

回头看，我的域名膨胀有几个明确的来源。

第一个是"以后可能用"。看到一个好词，觉得将来某个项目能用上，先注册着。实际上大部分项目没做成，域名就一直躺着。

第二个是"防御性注册"。担心别人注册相似域名做坏事，于是把几个变体都买了。这个动机合理，但只对真正有品牌的域名成立。

第三个是"折腾期"。有一段时间我热衷于尝试各种建站方案，每试一个就注册一个域名，试完就忘。

第四个是"帮朋友注册"。帮人代注册，结果对方不用了，域名还在我名下续费。

这四个来源加起来，就是那十几个域名的来历。

## 九、续费价和 API 价的分离

有一点值得单独说：域名的零售价和它的 API 能力是两回事。

很多注册商提供 API，可以程序化管理域名，但 API 的可用性和价格政策无关。有的便宜注册商 API 很难用，有的贵注册商 API 很完善。

如果你只是个人持有几个域名，用不上 API，价格就是唯一因素。

如果你管理几十上百个域名，或者要做自动化续费监控，那 API 的可用性就值钱了，值得为它多付一点。

我现在的规模很小，所以完全按价格选，不再为"可能用得上"的 API 付溢价。

## 十、隐私保护是不是必要

注册域名时，注册信息会进入公开的 WHOIS 数据库。隐私保护服务会把你的姓名、地址、邮箱替换成代理信息。

现在很多注册局已经默认隐藏个人信息，或者只对特定用途开放查询。但在一些后缀上，信息仍然是公开的。

公开的后果是收到大量垃圾邮件、推销电话，甚至被诈骗盯上。

我的判断是：个人域名一律开隐私保护，价格通常几十块一年，值得。企业域名如果本身信息就该公开，可以不开。

有些注册商把隐私保护打包在价格里，有些单独收费，比价时要算进去。

## 十一、DNS 托管不必跟着注册商

注册商通常送免费的 DNS 托管，但你不一定要用。

DNS 的质量影响解析速度和稳定性。免费 DNS 在大多数场景够用，但如果你对解析有要求，可以换到专门的 DNS 服务商。

换 DNS 只需要在注册商那里改 NS 记录，不影响域名所有权。这一步随时可以做，不涉及转移。

我用的是第三方 DNS，原因是它有更细的解析记录管理和更好的全球节点。代价是多一个地方要维护，以及多一份账号安全风险。

## 十二、证书和域名是绑定的

域名换了，证书要重签。这一点在清理域名时容易被忽略。

如果你用免费证书，自动化签发的方案可以在域名解析生效后自动签发，成本几乎为零。

如果你买了付费证书，换域名意味着重新买，这是一笔额外支出。所以在决定弃用某个域名之前，先看看它上面有没有还在有效期内的付费证书。

我现在全部用自动化签发的免费证书，弃用域名时只需要停掉续签任务，没有沉没成本。

## 十三、监控和提醒

清理之后，我给剩下的域名加了一层监控。

监控的内容很简单：到期时间、解析是否正常、证书是否即将过期。

到期提醒设在到期前六十天和三十天各一次，发到我每天都在看的渠道，而不是注册商的邮件。注册商的邮件太容易被当成营销邮件忽略。

解析监控是定时请求一个已知路径，看返回是否正常。这能抓到 DNS 配置错误、源站挂掉等问题。

证书监控是检查剩余有效期，少于十四天就提醒。自动化续签偶尔会失败，这个提醒是最后一道防线。

## 十四、我的清理标准

清理的时候，我用三个问题过一遍。

第一个问题：过去十二个月，这个域名有没有产生过访问？没有访问的，基本可以放弃。

第二个问题：未来十二个月，我有没有具体的计划要用它？注意是具体计划，不是"可能"。

第三个问题：这个域名有没有绑定的东西？邮件、账号、外链、证书、以及别人的书签。有绑定的要单独评估迁移成本。

三个问题过完，十几个域名里只留下了三个：一个主站、一个邮箱用、一个备用。

## 十五、品牌保护的边界

前面提到防御性注册，这里要说清楚边界。

防御性注册只对"有品牌价值"的域名成立。如果你有一个小有名气的项目，别人用相似域名做仿冒，会伤害你的用户，这时候注册几个变体是合理的。

但如果你只是一个个人博客，没有商业价值，防御性注册纯属浪费。没人会仿冒一个日访问几十的站点。

判断标准是：这个域名如果被别人拿去用，会不会有人受骗。答案是不会，就不必防。

## 十六、值得留和该扔的

留下来的三个域名，各有明确用途。

主站域名是核心资产，所有内容、外链、搜索收录都在上面，不能动。

邮箱域名用于收发邮件，很多服务的账号绑定在它上面，迁移成本高，留着。

备用域名是一个更短更好记的变体，将来如果主站要换品牌，它是候选。

扔掉的都是没有访问、没有计划、没有绑定的。扔之前我做了一次全量检查：确认没有邮箱在用、没有服务回调指向它、没有自动任务依赖它。

这一步不能省。有些服务把域名当回调地址，域名一停，服务就静默失败，几个月后才发现。

## 十七、域名和邮箱的耦合

域名和邮箱的关系比想象中紧。

只要你的邮箱地址用了自有域名，这个域名就不能随便弃用。因为邮箱是账号找回的入口，几乎所有服务的重置密码都发到这里。域名一停，你就失去了找回能力。

更麻烦的是历史邮件。停用域名之后，旧邮件还躺在邮箱服务商那里，但你无法再收新邮件，也无法验证"这个邮箱属于你"。

我的做法是：只要还有任何账号绑定了某个域名邮箱，这个域名就必须留着。清理之前先做一次账号梳理，把所有用这个邮箱注册的服务找出来，逐个改绑。

这一步很耗时，但比域名过期之后发现找不回账号要好。

## 十八、DNS 记录里的隐藏依赖

除了邮箱，DNS 记录里还藏着很多依赖。

最常见的是验证记录。很多服务在绑定域名时会让你加一条 TXT 记录，证明你拥有这个域名。这条记录加了之后，服务会定期检查。域名一停，验证失效，服务跟着挂。

还有子域名的指向。可能有一个你早就忘了的子域名，指向某个已经下线的服务，但某个自动化任务还在请求它。

以及 CNAME 记录。如果某个第三方服务用的是 CNAME 接入，它依赖你的域名解析，停止解析会导致服务中断。

清理前我会把全部 DNS 记录导出来，逐条看用途。看不懂的记录先别删，查清楚再说。这个习惯救过我一次，有一条记录是一个早就忘记的监控服务的回调地址。

## 十九、注册商的账号安全

域名是账号资产，账号被盗等于域名被转走。

基本的防护有三层：强密码、两步验证、以及注册商提供的域名锁定。

域名锁定是一个状态标记，开启之后域名不能被转移。要转移必须先解锁。这个功能免费，但很多人不知道，也不开。

两步验证要注意备份恢复码。有些人开了两步验证，手机丢了，恢复码也没存，结果自己被锁在账号外面，比被盗还麻烦。

我现在的做法是：所有域名放在一个专门的账号里，和日常邮箱分开；开启两步验证并离线保存恢复码；开启域名锁定；定期检查账号的登录记录。

## 二十、批量管理的脚本

域名多了之后，手工管理容易出错，可以写脚本。

最常见的需求是查到期时间。注册商一般提供 API，可以拉取账号下所有域名的到期日和状态。把这些数据存进一张表，每天更新。

有了这张表，就能做很多事：算出未来三个月要续费的域名和总金额；标记已经过期或即将过期的；发现状态异常的，比如被锁或者解析停止。

我写过一个很短的脚本，每天早上跑一次，把结果输出成一段文字发给自己。几十行代码，但省去了每月手动登录查一遍的麻烦。

脚本要注意的是别把凭据写死在代码里。用环境变量或者专门的凭据管理，代码可以放在公开仓库里。

## 二十一、什么时候该换域名

有时候不是弃用，而是换一个更好的。

换域名的成本很高：所有外链失效、搜索收录要重新积累、读者要重新记。所以只有在收益明显大于成本时才值得。

常见的换域名理由：原来的后缀太贵，续费压力大；原来的名字有商标风险；或者品牌升级，名字不再合适。

换的时候要做完整的重定向。旧域名的每个路径都要 301 到新域名的对应路径，而不是全部跳到首页。全部跳首页会让搜索引擎认为旧链接失效，收录权重传不过去。

重定向要长期保留，至少保留一到两年，直到确认外部流量已经迁移完成。

## 二十二、关于域名投资的两个误解

清理过程中我看了不少域名投资的内容，有两个说法值得辨析。

第一个说法是"好域名永远涨"。这个结论对极少数单词域名成立，对绝大多数普通域名不成立。市场上有海量没人要的域名，挂几年也卖不出去，每年的续费就是纯亏损。

第二个说法是"先注册等升值"。这个策略的前提是你能承受长期持有成本，并且判断准确。大部分人注册的"好名字"，在别人眼里并不值钱，因为没有对应的需求。

真正的域名投资是一门信息生意：知道谁在买、什么词有价值、什么时候出手。它和建站完全是两件事，不要因为自己会用域名，就以为自己也懂域名交易。

## 二十三、把续费做成一项年度预算

现在我把域名续费放进了年度预算，和服务器、软件订阅放在一起。

做法很简单：每年年初把所有订阅类支出列成一张表，写下金额和到期月，算出全年总额。这笔钱提前留出来，不要等到扣款时才发现。

这张表还有一个作用：它让"沉默支出"变可见。以前这些钱是零星扣的，每笔都不大，感觉不到。汇总之后才发现，一年在这些小事上花掉的钱，够买一台不错的设备。

预算不是为了省钱而省钱。它只是让你在花钱这件事上有意识，而不是被自动扣款推着走。这一年我砍掉的域名，省下的钱不多，但那种"我知道自己的钱去哪了"的清楚感，比钱本身更值。

## 二十四、把域名当资产还是负债

最后说一点感受。

域名很容易被当成资产：稀缺、增值、可交易。这个叙事在域名投资圈里成立，但对普通建站者不成立。

对绝大多数人来说，域名是负债。它每年要花钱，需要维护，会过期，还要占用注意力。

把它当负债看，决策就简单了：只留真正在用的，其余果断放弃。

我现在的做法是每年固定时间做一次盘点，把所有订阅性质的支出列出来，域名只是其中一类。看完之后砍掉一部分，剩下的继续。这个过程本身不产生价值，但它能防止那些安静的小额扣款慢慢堆成一座山。
